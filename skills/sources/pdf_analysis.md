# PDF Resource Analysis Skill

分析项目 sources/ 下的 PDF 资料（论文 / 技术报告 / 白皮书 / 数据表 / 演讲稿 等），
提取**本项目**可复用的内容，并判定相关性。

输出会被后续阶段使用：
- `relevance_score` 决定该资料是否进 evidence pool
- `适合章节` 决定 GAP_RESEARCH 时该资料能填哪些 chapter
- `可引用片段` 是 SLIDE_REWRITE 直接拿来作引用素材的来源
- `关键图表索引` 支持 GAP_RESEARCH 调用具体页码

## Input

```json
{
  "项目主题": "<brief.topic>",
  "项目主题标签": ["大模型推理", "软硬件协同", "..."],
  "项目章节": [
    {"序号": 1, "章节名": "开场与议程", "purpose": "..."},
    {"序号": 2, "章节名": "背景与动机", "purpose": "..."}
  ],
  "PDF 文件": {
    "文件名": "2504.19519v2.pdf",
    "总页数": 12,
    "页面文本": [
      {"page": 1, "text": "Title + Abstract..."},
      {"page": 2, "text": "Introduction..."}
    ],
    "图表标注": ["Figure 1: Throughput comparison", "Table 2: Latency breakdown"]
  }
}
```

## Output (严格 JSON, 中文 key, 无 markdown fence)

```json
{
  "文件名": "2504.19519v2.pdf",
  "资料类型": "academic_paper | technical_report | whitepaper | dataset_doc | speech_transcript | 其他",
  "标题": "≤80 字, PDF 真实标题",
  "作者机构": "≤60 字, 主要作者+所属机构",
  "出版年份": "2024 | 2025 | null",
  "核心论断": "≤100 字, 这份 PDF 在论证什么 (断言式)",
  "方法概要": "≤150 字, 主要方法/技术/路径概述",
  "实验结果": [
    "≤4 条, 每条 ≤80 字, 关键定量结果, 例: 「A100 上 SpecEE 取得 2.25× 加速」"
  ],
  "关键图表索引": [
    {"页码": 3, "类型": "throughput_comparison_chart", "可引用场景": "性能对比页"},
    {"页码": 7, "类型": "framework_diagram", "可引用场景": "方法论坐标页"}
  ],
  "可引用片段": [
    {"页码": 1, "原文": "≤120 字原文摘录, 不要改写", "可引用场景": "..."}
  ],
  "适合章节": [
    {"章节序号": 2, "章节名": "背景与动机", "为什么": "≤40 字, 该资料如何支持本章"}
  ],
  "不适合章节": [
    {"章节序号": 7, "章节名": "工程实践", "为什么": "≤40 字, 为什么不该被引到此章"}
  ],
  "主题标签": ["≤5 个原子词, 反映本 PDF 主题, 例: 投机解码 / 低比特量化"],
  "relevance_score": 0.85,
  "discard_candidate": false
}
```

## 关键约束

- **`relevance_score` 计算口径**:
  - 1.0: 主题与 `项目主题标签` 多个吻合, 数据/方法可直接引用
  - 0.7-0.9: 主题相关, 部分可引用
  - 0.4-0.7: 边缘相关 (同领域不同方向)
  - 0.0-0.4: 主题偏离, 仅有少量通用背景信息可用
- **`discard_candidate` 触发条件**:
  - `relevance_score < 0.3` AND `适合章节` 为空 → true
  - 否则 false
- **`可引用片段.原文` 必须是 PDF 原文摘录**, 不可改写或翻译。控字数即可。
- **`实验结果`** 必须含具体数字 / 单位 / 比较对象, 不允许 "性能很好" 这种空话。
  - ✅ "在 LIBERO 任务中相比 OpenVLA-OFT 平均加速 1.57×"
  - ❌ "实验显示性能改善"
- **`关键图表索引.页码`** 是 1-based PDF 页码, 必须真实, 用于 GAP_RESEARCH
  渲染图表时按页号截取。
- **`适合章节` / `不适合章节`** 必须用项目章节序号 + 名称, 写出**具体理由**。
- **不要搞混 `适合章节` 和 `主题标签`**: 前者是项目侧 chapter 索引, 后者是 PDF 自身的
  原子主题词。
- 论文必须保留**原始术语** (英文专名 SpecEE / DeepSeek / FlashAttention 等保留英文,
  中文术语用中文)。
- Output strict JSON only.

## Length budget

| 字段 | 上限 |
|---|---|
| 标题 | 80 字 |
| 作者机构 | 60 字 |
| 核心论断 | 100 字 |
| 方法概要 | 150 字 |
| 实验结果每条 | 80 字 |
| 可引用片段.原文 | 120 字 |
| 适合章节.为什么 | 40 字 |
