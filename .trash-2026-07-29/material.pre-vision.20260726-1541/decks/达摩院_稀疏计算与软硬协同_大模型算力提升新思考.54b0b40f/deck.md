# 稀疏计算与软硬协同：大模型算力提升新思考

## 整篇 deck 的论述弧线
研究背景 → 研究思路 → 代表成果 → 范式思考 → 研究展望

## section 之间的逻辑关系
1. **封面** — 全 deck 的门面页，抛出「稀疏计算与软硬协同」总题与演讲者身份，为后续算力供需矛盾与三条技术主线定调，尚未展开论述。
2. **研究背景与核心问题** — 承接封面/agenda，建立全书前提：先摆算力供需矛盾，再给算力衡量方式，进而引出软硬协同思路，最终收束为稀疏化/量化/架构设计三大核心问题，为后续方法章铺路。
3. **主要研究成果概览** — 承接 motivation，将三条核心问题落地为三组代表成果（信息驱动稀疏、稀疏加速器、结构化稀疏硬件），逐组递进展示，为后续深入方法章节建立总览框架。
4. **FlashDecoding++推理引擎优化** — deck 首个 case_study，把前文软硬协同思路落到推理引擎优化上；内部由引擎发展 RoadMap 切入，定位注意力/线性两大算子瓶颈，引出 FlashDecoding++ 三招优化并以加速结果收尾。
5. **软硬件协同与FP8训练** — 承接前四章单点成果，用「提问—方法—实例」把稀疏计算范式升维到软硬件协同层面，以 FP8 训练为压轴案例，论证协同优化是突破算力瓶颈的系统性路径。
6. **FlightLLM大模型推理加速** — 作为第二个软硬件协同实例，承接稀疏化主线，用 FlightLLM 论证：结构化稀疏+可重构 DSP 链在 FPGA 上可胜过更先进工艺 GPU，为稀疏范式思考再添硬证据。
7. **FlightVGM视频生成加速** — 作为第三个代表成果，把稀疏化思路落到视频生成场景：由传统视频处理引出视频生成任务，提出信息驱动稀疏化核心思想，再以FlightVGM的分组相似性挖掘＋FPGA硬件设计＋实验结果完成算法-硬件闭环论证。
8. **稀疏范式思考与TB-STC** — deck 收尾章：先把前几个成果升华为「稀疏计算范式」思考，再以 TB-STC 作为软硬协同压轴案例，从核心思想到硬件架构再到实验结果完整落地，呼应全 deck 主线。
9. **总结、展望与结束** — 收束全 deck：先重思稀疏与 Tensor Core 范式，再升维到通专结合通往 AGI 的愿景，随后总结成果并铺陈异构算力网络等多项研究展望，最终致谢结束。
