# FlightVGM：视频生成模型高效推理加速

## 整篇 deck 的论述弧线
背景 → 挑战 → 方法 → 实验 → 总结

## section 之间的逻辑关系
1. **封面** — 作为整个 deck 的开篇门面，以论文标题 FlightVGM 直接亮明主题——面向视频生成模型的高效推理加速，为后续问题背景与三项技术方法奠定基调。
2. **目录** — 全 deck 目录页，紧承 cover 列出章节骨架（Background 等），为后续技术章节建立导航坐标；内部由两版 Contents 页并置，形成目录呈现/强调的递进。
3. **视频生成模型与硬件背景** — 作为方法章节前的背景铺垫：先立起「VGM 推理开销大」这一动机，再从生成式 AI→Sora→VGM 结构→与 LLM 差异→GPU 低精度硬件趋势层层递进，为后文稀疏/混合精度/调度三技术埋下问题伏笔。
4. **GPU难以利用稀疏与低精度** — 问题章：先立稀疏+低精度这两大可优化特性，再论证 GPU 架构无法利用它们，并综述 DFX、LLM 加速器等硬件先例，为下文 FPGA 三项技术铺垫必要性。
5. **三项加速技术** — deck 方法核心章。先以帧间相似性观察铺垫，再依次展开 Tech.1 在线激活稀疏、Tech.2 可配置 DSP58 混合精度、Tech.3 动静结合调度，三技术层层递进构成完整加速方案。
6. **实验设置与性能结果** — 承接前三项技术方案，用实测数据兑现「显著加速与能效提升」承诺：先交代模型/数据集与硬件资源占用，再逐项给出相对 GPU 的加速比、能效比与端到端案例。
7. **混合精度消融与增益分析** — deck 收尾的量化论证章：以混合精度为核心，先经章节内导航定位，再展开消融，最终用 ~30% 面积节省、~7.5 增益坐实 DSP58 混合精度设计的价值。
8. **致谢** — deck 收束页，在方法与实验论证完成后以致谢作结，无内部叙事弧线，仅承担礼节性收尾功能。
