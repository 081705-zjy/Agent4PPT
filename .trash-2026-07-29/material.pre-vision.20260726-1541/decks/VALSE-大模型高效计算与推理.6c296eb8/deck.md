# 大模型高效计算与推理

## 整篇 deck 的论述弧线
背景动机 → 问题拆解 → 算法优化 → 系统优化 → 硬件架构 → 趋势总结

## section 之间的逻辑关系
1. **大模型高效计算与推理** — 全 deck 的门面页，单页封面。确立「大模型高效计算与推理」主题、演讲者戴国浩与上海交通大学身份，为后续 Token 经济学切入及算法/系统/硬件三层论述定调。
2. **Token经济学与推理成本** — 作为方法章节前的动机铺垫，以产业革命类比引出「Token=新电能」，再借黄仁勋五层蛋糕论证推理成本是价值转化核心，为算法/系统/硬件三层优化立论。
3. **推理优化三层拆解总览** — 承接 Token 经济学的成本论证，抛出算法/系统/硬件三层优化框架，为后续三大方法章节搭好总纲与索引骨架。
4. **算法层：投机计算与投机解码** — deck 方法论三层的第一层（算法层）。内部走「总述→投机计算(方法论+典型方法+效果)→投机解码(同结构)→二者结合→我方实践」的对称双线弧，把加速手段落到自研成果。
5. **系统优化：调度与多卡并行** — 承接算法层投机计算，从系统层拆解推理优化；先立「前端调度—后端并行」二分框架，再前端（请求调度、资源分配）、后端（多卡并行、通信、算子）逐层展开系统手段。
6. **硬件架构：突破四类受限** — 推理优化三层框架的硬件层收尾。先回顾拆解全景并定位硬件层，再以「性能由四类受限决定」为总纲，逐一给出计算/存储/带宽/通信四受限的突破方法论。
7. **未来趋势与杰文斯悖论** — 作为收尾章，把前面算法/系统/硬件三层优化收束为「软硬协同」总趋势，再用杰文斯悖论反转论证：效率提升反而推高总算力需求，为价值判断作结。
8. **参考文献** — deck 收尾章，把正文按算法/系统/硬件三层的引用来源集中列出，为全 deck 的论述提供文献支撑与可追溯性，本身不推进论点。
9. **结束页** — 全 deck 收尾页，以讲者署名与日期作结，标志软硬协同优化论述闭合，不再引入新内容，仅提供致谢与联系归属。
