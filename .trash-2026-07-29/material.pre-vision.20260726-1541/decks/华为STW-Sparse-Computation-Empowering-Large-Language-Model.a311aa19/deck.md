# 稀疏计算赋能大语言模型

## 整篇 deck 的论述弧线
背景成本 → GPU加速 → 稀疏计算 → 硬件加速 → 领域模型 → 新范式

## section 之间的逻辑关系
1. **封面** — 全 deck 门面。仅一页，抛出「稀疏计算赋能大语言模型」总命题与作者身份,为后续算子/硬件/模型三层论证定调,不展开子论点。
2. **大模型算力与能耗成本** — 为全 deck 铺垫问题动机:从 LLM 广泛应用切入,层层论证算力、能耗、成本高昂与乘法器瓶颈,末页以「如何改进」设问引出稀疏计算三层方案。
3. **GPU算子加速:FlashDecoding++** — 作为三层加速路径的第一层(算子层),以FlashDecoding++论证GPU上注意力算子优化可带来实测加速。内部弧线:背景铺垫→技术方案→实验数据双重验证。
4. **Scaling Law下的新路径** — 承接前三层加速工作,从Moore's Law转向Scaling Law视角,论证在延迟-精度权衡下有三条新路径(Scaling/高效模型/新基础模型),把前文技术上升为方法论收束。
5. **稀疏计算与FPGA加速:FlightLLM** — 承接算子加速后，本章下沉到硬件层：从摩尔定律放缓的算力困境切入，论证稀疏计算的必要性，再落到灵活N:M稀疏+Sparse DSP的FPGA方案，用FlightLLM实测超越GPU收束。
6. **视频生成模型稀疏加速:VGAcc** — 承接算子/硬件层,把稀疏计算下沉到视频生成这一垂域。先立视频生成的高算力痛点,再拆出全注意力稀疏计算与稀疏感知PE两项技术,末页用VGAcc实测收尾,补齐稀疏三层加速的模型层案例。
7. **稀疏驱动新范式:MoE/MoD** — 作为方法论收尾章,把前面算子/硬件层的稀疏加速上升到模型范式层。由重思Transformer切入,依次引出MoE(宽度稀疏)、MoD(深度稀疏),最终归纳稀疏驱动的新基础模型。
8. **稀疏新基础模型:TB-STC** — 作为 deck 收官 method 章,把稀疏从算子/硬件推进到基础模型训练层:先立「带稀疏的新基础模型」愿景,落到 N:M 稀疏训练三阶段,再抛出 TB-STC 可转置块状稀疏这一核心创新,以两个算子技术支撑并用端到端实验收尾。
9. **总结与展望** — 作为全 deck 收尾，先用 Scaling Law 回收「算子-硬件-模型三层稀疏加速」主线，再以扩展工作外延未来方向，最后落到讲者身份与愿景，完成从技术总结到人的收束。
10. **附录:技术细节备份** — 作为全 deck 附录,不承担对外叙事,而是把正文压缩掉的技术细节铺开:先展开 FlashDecoding++ 的 softmax/GEMM/tiling/编译调优内部机制,再补稀疏精度与硬件权衡,末尾速查 MoE/MoD 原理,供答疑深挖。
